# Datasets Directory

This directory stores raw and preprocessed datasets used by ReLife AI:

1. **NASA Battery Aging Dataset**:
   - Source: NASA Prognostics Center of Excellence (PCoE) Battery Data Set.
   - Reference: B0005, B0006, B0007, B0018 run-to-failure battery charge/discharge telemetry.
   - Used for training the State of Health (SOH) and Remaining Useful Life (RUL) cycle prediction models.

2. **Market Valuation Reference Data**:
   - Secondary market price listings and hardware depreciation curves.
   - Any synthetic reference datasets are strictly marked with `"is_synthetic": true`.
